This entry writes the error message a kitchen toaster shows its owner after toasting the same bread three times and still finding it wanting: deadpan, a little obsessive, and resigned to the fact that it will never be enough. It reads like a real appliance error code with a very small existential crisis behind it.

## Run it

```sh
python3 main.py
```

The program writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` if that variable is not set). It validates the line first: non-blank, a single line, and at most 120 characters. Standard library only, no network, deterministic — every run produces the same bytes.
